# 🗺️ Roadmap - Study Rally

> Lista de mejoras para que cualquiera pueda proponer. ¡Toma una y haz un PR!

## Level 1 - Contenido Fácil (good first issue)
- [ ] Agregar 10 preguntas de Razonamiento Verbal
- [ ] Agregar 10 preguntas de Razonamiento Matemático
- [ ] Agregar Level 3: Historia del Perú (10 preguntas)
- [ ] Agregar Level 4: Geografía del Perú

## Level 2 - Features Medias
- [ ] Sistema de rachas (streak x2 puntos)
- [ ] Sonido retro cuando aciertas/fallas
- [ ] Modo oscuro / claro
- [ ] Animación de subir de nivel

## Level 3 - Features Avanzadas
- [ ] Tabla de líderes con localStorage
- [ ] Compartir puntaje en WhatsApp
- [ ] Modo examen 60 preguntas / 60 min
- [ ] Guardar progreso por usuario

### ¿Cómo proponer?
1. Ve a Issues > New Issue
2. Elige "Nueva Pregunta" o "Idea de Mejora"
3. Haz tu PR y linkea el Issue
