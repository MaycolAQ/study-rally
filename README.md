### 🏆 How it works?

- 🎯 **10 Random Questions** - Math & Verbal Reasoning from `problem_bank.js` (100+ curated problems)
- 👤 **Name Optional** - Skip with Cancel / Enter, play anonymously
- 📊 **Top 15 Live Ranking** - LocalStorage powered, real-time leaderboard (`ranking.js`)
- 🤖 **Adaptive AI** - `adaptive_ai.js` detects your weak spots and trains them
- 🌐 **100% Frontend** - No backend, fast, works offline on GitHub Pages
- 📱 **Mobile First** - Perfect for WhatsApp sharing
